Імпорт / експорт каталогу

Один CSV/XLSX для карток товарів, SKU, цін і залишків. Preview → backup → Apply → verify → rollback.

1. Основний імпорт каталогу — CSV / XLSX

Одна строка = один SKU. Кілька строк одного product_id або slug збираються в одну Product Card v3. Ціни та залишки прив’язуються тільки через точні commerce_product_key / commerce_sku_key — без підбору за назвою чи фасуванням.

Рекомендований сценарій: «Експорт XLSX» → змінити потрібні клітинки → завантажити назад → Preview → Apply. Порожня клітинка = не змінювати існуюче значення. Поля description, how_it_works, application, composition, benefits_json і characteristics_json формують повну інформаційну картку товару. У application можна додати офіційний URL виробника окремим рядком — на публічній картці він буде показаний окремо як «Офіційне джерело», а не як частина рецепту. Щоб очистити sale_price або stock_qty, використовуйте __CLEAR__. Відсутні у файлі SKU не видаляються. Publication імпорт не вмикає і не вимикає.
