/opt/bb610-market

ladima75-source/bb610-market

Branch:

main

---

## GitHub access

VPS is connected to GitHub using a dedicated SSH Deploy Key with write access.

Deploy Key name:

BB610 Market VPS

SSH host alias:

github-bb610-market

Private key:

/root/.ssh/bb610_market_github

Git remote `origin` uses this SSH alias.

---

## IMPORTANT: Source vs Generated vs Runtime

Git stores source code and source catalog data.

The production server also contains generated files and live runtime data which MUST NOT be treated as Git source.

Architecture:

SOURCE -> Git

GENERATED BUILD -> generated by build tools

RUNTIME / LIVE DATA -> stored on VPS

---

## Runtime data

Directory:

backend/runtime/

This directory may contain:

- orders database
- uploaded product images
- other production/live data

`backend/runtime/` MUST NOT be committed to Git.

Before deleting, replacing, migrating or rebuilding this directory, make a backup.

---

## Generated catalog output

Generated catalog files are build output and are not the source of truth.

Examples include:

- products/* generated product pages
- categories/* generated category pages
- data/catalog.generated.json
- data/catalog.runtime.js
- feeds/*
- sitemap.xml
- robots.txt

Catalog generation is performed by:

tools/build_catalog.py

Generated output should be recreated from source data rather than maintained manually in Git.

---

## Operational rules

Before making server or deployment changes:

1. Run `git status`.
2. Verify which files are SOURCE, GENERATED or RUNTIME.
3. Never run `git add -A` blindly.
4. Do not modify `.gitignore` without understanding this architecture.
5. Never delete or overwrite `backend/runtime/` without a backup.
6. Do not manually maintain generated product/category pages when they can be rebuilt by the catalog generator.
